# ポケモンと ブロックパズル！（Ver.1.1 試作版）

小学1年生でも遊びやすい、スマホの横向き（ランドスケープ）・パソコン両対応の落ちものブロックパズルです。
GitHub Pagesでそのまま公開できます。**サーバー・データベース・APIキーは不要です。**

## 機能
- 4つの難しさを最初に選べます：レベル1「はじめて」／2「ゆっくり」／3「ふつう」／4「チャレンジ」
- **スマホ横向き専用レイアウト**：左に十字キー、中央にゲーム盤、右に大きな回転ボタン
- 左の十字キー：◀ ひだり／▶ みぎ／▼ 1マス下げる／▲ 一気に下まで落とす（すとん！）
- 右の紫ボタン：ブロックを回転（くるり）
- 十字キーを長押ししたまま、もう片方の指で回転ボタンを押せます（マルチタッチ対応）
- スコア、消した列数、プレイ中のレベル、ステージ別ハイスコアを表示
- 次のブロックのプレビュー、着地点のガイド（うすいかげ）
- あそびかたの図解、途中で止める・再開・再挑戦、効果音のオン／オフ
- 5列消すごとにプレイ中のレベルが上がり、少しずつ速くなります
- 最高スコアは、同じ端末のブラウザ内に保存されます（localStorage）

## GitHub Pagesで公開する方法
1. GitHubに新しい公開（Public）リポジトリを作成します。名前は例として `pokemon-blocks`。
2. このフォルダーのファイル **`index.html`、`style.css`、`game.js`、`icon.svg`** をすべてリポジトリの一番上（ルート）へアップロードしてコミットします。ZIPファイルをそのままアップロードするのではなく、解凍した中のファイルをアップロードしてください。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment → Source: Deploy from a branch**、**Branch: main**、フォルダー **/(root)** を選び、**Save** を押します。
5. GitHub Pagesの画面に表示された公開URLを開きます。通常は `https://ユーザー名.github.io/pokemon-blocks/` の形式です。

## スマホで遊ぶとき
- スマホを横向きにしてください。画面サイズに合わせてボードと操作ボタンが配置されます。
- 十字キーと回転ボタンを両手の親指で操作します。
- ホーム画面の「レベル1 はじめて」を選ぶと、落下速度が最もゆっくりです。

## パソコンでも遊べます
- ← →：左・右へ動かす
- ↑ または X：回転
- ↓：1マス下げる
- Space：一番下へ落とす
- P：一時停止／再開

## スコアについて
- 1列：100点／2列同時：250点／3列同時：450点／4列同時：700点
- ブロックを置くと5点、下に1マス進めると1点、すとん！で1マスにつき2点
- 消した列数5つごとにレベルアップ。点数はわかりやすさ優先で固定です。

## 構成
- `index.html`：画面と説明
- `style.css`：見た目・スマホ対応
- `game.js`：ゲーム動作
- `icon.svg`：試作品用のオリジナルアイコン

外部サービスから画像を取得せず、インターネットにつながっていない状態でも、一度ファイルを保存していればローカルで遊べます（GitHub Pagesへの初回アクセス時は接続が必要です）。
